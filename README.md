
# Task 5 – Cyber Incident Response Plan
Internee.pk Cybersecurity Internship

## What this task is about
Prepare for a cyber incident by simulating a ransomware attack,
using MITRE ATT&CK, and writing an incident response plan.

## What I did
- Investigated the REvil (Sodinokibi) ransomware room on TryHackMe using Mandiant Redline
- Found the encrypted files (.t48s39la), the ransom note, the fake decryptor and the infection file
- Checked the sample on VirusTotal (65/71 vendors flag it as ransomware)
- Mapped the attack to MITRE ATT&CK: T1486 Data Encrypted for Impact and S0496 REvil
- Wrote a six-phase incident response plan with roles, severity levels and a ransomware playbook
- Wrote a one-page staff training guide
- Used the Kaseya VSA attack (July 2021) as a public case study
